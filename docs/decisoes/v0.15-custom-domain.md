## Lições

- **Token Vercel expira** — sempre checar antes de operações críticas
- **Cloudflare proxy deve estar cinza** (DNS only) durante validação inicial — proxy laranja (laranja) bloqueia a verificação SSL
- **CNAME `cname.vercel-dns.com`** é o destino padrão para subdomínios custom na Vercel
- **SSL automático** via Vercel (Let's Encrypt) — sem necessidade de configurar manualmente
