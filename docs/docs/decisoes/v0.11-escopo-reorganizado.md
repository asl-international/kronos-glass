# v0.11-teste — Escopo reorganizado

**Data**: 15/07/2026
**Status**: implementado em `index-teste.html` (em validação)

## Contexto

Marcelo: "atualmente ele está deixando colocar apenas uma nota por aba, preciso que reformule absolutamente essa visão para um modo em que eu consiga acessar tudo de modo totalmente intuitivo. Repasse completamente, está tudo muito ruim. Faça tudo na de teste, não me pergunte nada, divida em partes. Esta feio, truncado, confuso, jogado."

O print mostrava cards vazios e cards com lixo de teste, sem distinção visual.

## Diagnóstico

1. **Cards vazios = cards preenchidos** (mesma aparência)
2. **Sem agrupamento por tipo** (notas misturadas com links/planilhas)
3. **Sem filtro** por tipo
4. **Sem resumo da página** ("X notas, Y links, Z planilhas, W vazios")
5. **Vazios competindo por atenção** com notas que têm conteúdo

## Decisões de design

### 1. Header de resumo no topo de cada escopo
- 4 pills de contagem: "X notas · Y links · Z planilhas · W vazios"
- Cores diferentes: pill `filled` (texto claro) vs `empty` (tracejado, texto dim)
- Mostra em 1 segundo o que tem em cada escopo

### 2. Filtro por tipo (pills inline)
- 5 pills: **Todos** / **Notas** / **Links** / **Planilhas** / **Docs**
- Estado persiste por escopo (salvo no `kronos_state_v1`)
- Empty state quando filtro não tem nada: "Nada aqui no filtro X. Ver todos"

### 3. Agrupamento visual por tipo
Cada tipo de item vira um grupo com header próprio:
- **NOTAS (N)** — cards colapsáveis grandes
- **LINKS (N)** — cards compactos com ícone azul
- **PLANILHAS (N)** — cards compactos com ícone verde ⊞
- **DOCS (N)** — cards compactos com ícone roxo D
- **OUTROS (N)** — sections, videos, images
- **VAZIOS (N)** — só aparece se toggle ligado

Cada header tem: nome do tipo + count + linha horizontal decorativa.

### 4. Vazios escondidos por padrão
- Toggle "Mostrar vazios" (off → on)
- Quando ligados, ficam num grupo separado com:
  - Ícone ∅ tracejado
  - Nome dim
  - Descrição "slot vazio — clique em ✎ pra preencher"
  - Só botão de editar (sem mover/apagar)

### 5. Cards de items reformulados
Cada item compacto tem:
- **Ícone de tipo colorido** (link=azul ↗, doc=roxo D, sheet=verde ⊞, video=vermelho ▶, image=amarelo ◆)
- Nome + descrição (ou host da URL)
- Ações só no hover (opacity 0 → 1)

### 6. Estado de UI por escopo
- Filtro + toggle salvos no `kronos_state_v1`
- `SCOPE_UI[scopeKey] = { filter, showEmpty }`
- Função `setScopeUI(scopeKey, patch)` que chama `saveState()`

## Implementação

### CSS novo
- `.scope-summary` — header com pills de count
- `.scope-filter-pill` — pills de filtro
- `.scope-toggle-empty` — checkbox toggle
- `.scope-group` + `.scope-group-header` — agrupamento
- `.item-compact` + `.item-compact-icon` + `.item-compact-body` — cards reformulados
- `.scope-empty-state` — estado de filtro vazio

### JS novo
- `SCOPE_UI` (estado por escopo)
- `getScopeUI(scopeKey)` / `setScopeUI(scopeKey, patch)`
- `groupItems(items)` — agrupa por tipo (notes/links/sheets/docs/others/empty)
- `getTypeBadgeChar(t)` — ícone por tipo
- `renderItemCompact(scopeKey, subId, item, parentId)` — renderiza 1 item
- `renderScopeSummary(scopeKey, allItems)` — header com counts
- `renderScopeGroups(scopeKey, allItems)` — grupos respeitando filtro

### Funções atualizadas
- `renderSimpleScope` e `renderOperacao` reescritas pra usar `renderScopeSummary` + `renderScopeGroups`

## Validação

- Filtro funcional
- Toggle funcional
- Cards de items renderizam com ícones coloridos
- Agrupamento por tipo funcional
- Persiste entre navegações
