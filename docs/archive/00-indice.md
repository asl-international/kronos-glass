## Política de archive

> **Nunca deletar.** Mover pra `archive/` com data.

Quando uma versão fica obsoleta:
1. Mover pra `docs/archive/[nome]-[data].md`
2. Adicionar entrada nesta tabela
3. Atualizar link no doc de fonte (ex: STATUS.md aponta pro novo arquivo, mas menciona que tem versão antiga no archive)
