# v0.10-teste — Busca extensiva

**Data**: 15/07/2026
**Status**: implementado em `index-teste.html` (validado)

## Contexto

Marcelo: "Quando eu pesquisar, dar a opção de dar enter e ver as opções. Faça uma extensa pesquisa de tudo para que a busca pegue não apenas palavras chave, mas analogias, contexto, etc. Por exemplo, tem coisas de eventos presencial e não apareceu ai [print]."

O print mostrava que buscar "presencial" só trazia SOPs (Fase 4, Pré-análise, etc) e "Conhecimento", mas **NÃO trazia "Eventos Presenciais"** — porque títulos de produtos/áreas não eram indexados.

## Diagnóstico

A busca tinha 3 limitações:
1. **Títulos de produtos/áreas** (`Operação · Eventos Presenciais`, `Operação · Marketing`, etc) não eram indexados — busca por "evento", "presencial", "marketing" não achava essas "entry points"
2. **Stemming básico ausente** — "presencial" não casava com "presenciais", "opções" não casava com "opção"
3. **Sinônimos do domínio ausentes** — "mentorado" não casava com "aluno", "zapi" não casava com "whatsapp"
4. **Navegação por teclado ausente** — Enter/↑/↓ não funcionavam; tinha que clicar

## Decisões de design

### 1. Stemmer em PT
Sufixos tratados em ordem de especificidade:
- **Plurais**: `-s` (com exceções: `ss`, `is`, `us`), `-ais`→presenci, `-oes`→opção, `-es`
- **Gerúndio**: `-ando/-endo/-indo` → sufixo `-ar`
- **Passado**: `-ado/-ido` → sufixo
- **Sufixo adverbial**: `-mente` → remove

### 2. Mapa de 200+ sinônimos do domínio
Mapeia palavra de busca → stem canônico. Cobertura:
- **Modalidade**: presencial, online, remoto
- **Eventos**: workshop, encontro, live
- **Pessoas**: aluno = cliente = mentorado; ju = juliana; ro = roberta
- **Produtos**: kairos = kairós = mentoria; destrava = workshop destrava
- **Operação**: crm = pipeline; cpl, roas, roi
- **Marketing**: mkt, criativ, copy, headline
- **Indicadores**: meta = met; kpi, okr
- **Plataformas**: zouti, hotmart, asas, manychat, zap = whatsapp, vercel, canva

### 3. Indexação de títulos sintéticos
Nova função `pushSynthetic(scopeKey, nome, desc)` no `buildIndex()`:
- Indexa **TODOS** os títulos de camadas (Gestão, Operação, etc)
- Indexa **TODAS** as 7 sub-áreas de Operação
- Indexa **TODOS** os 5 produtos
- Indexa SOPs, Biblioteca, Conhecimento

Cada um com flag `isScope: true`. Quando clicado, **navega** pra área (não pra um item específico).

### 4. Navegação por teclado
- **Enter** → vai pro resultado selecionado (e fecha dropdown)
- **↑/↓** → navega entre os 8 resultados
- **Esc** → fecha busca (só quando busca tá focada)
- **Click** no resultado → mesmo comportamento do Enter
- **Highlight visual** do selecionado (fundo rosa `var(--pink-soft)`)

### 5. Refatoração do `fuzzyScore`
- Compara **stems** (não strings literais) com pesos:
  - Stem exato: +90
  - Stem prefixo: +60
  - Stem substring: +40
  - Levenshtein em stems: +50 (distância 1) / +20 (distância 2)
- Bonus +120 se **todos** os tokens da query casaram
