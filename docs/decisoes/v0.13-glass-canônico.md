## Contexto

Marcelo reclamou que o Layout C (Craft minimal) escolhido em v0.12 tava "quadrado cinza" e pediu uma rodada de opções. Mavis construiu 5 layouts full HTML (Bento, Editorial, Dense, Glass, Notion) e pediu pra Marcelo comparar.

## Decisão

**Glass escolhido** em 17/07/2026. Outros 4 layouts congelados em v0.13, não atualizam mais.

## Por que Glass

- **Identidade visual mais forte** (frosted glass + glow + rosa gradient)
- **Combina com a estética** dos layouts "Workshop Destrava Shopee" e "PSL · Página Super Legal" que o user trouxe como referência
- **Backdrop blur** dá sensação de profundidade e modernidade
- **Topnav glass** com `backdrop-filter: blur(20px) saturate(180%)` é o efeito mais marcante

## Como foi implementado

### CSS base (Glass)
```css
:root {
  --bg: #0a0612;
  --glass: rgba(255,255,255,0.04);
  --glass-border: rgba(255,255,255,0.08);
  --glass-border-hover: rgba(236,72,153,0.4);
  --pink: #ec4899;
  --pink-soft: rgba(236,72,153,.15);
  --pink-glow: rgba(236,72,153,.5);
  --purple: #a78bfa;
}

body::before {
  content: "";
  position: fixed;
  inset: 0;
  background: radial-gradient(circle at 15% 20%,rgba(236,72,153,0.25) 0%,transparent 40%),
              radial-gradient(circle at 85% 80%,rgba(139,92,246,0.22) 0%,transparent 45%),
              radial-gradient(circle at 50% 50%,rgba(59,130,246,0.12) 0%,transparent 60%),
              var(--bg);
  z-index: -2;
}

body::after {
  /* grid de pontos sutil */
  background-image: radial-gradient(circle,rgba(255,255,255,0.02) 1px,transparent 1px);
  background-size: 24px 24px;
}
```

### Topnav
```css
.topnav {
  background: rgba(10,6,18,0.55);
  backdrop-filter: blur(20px) saturate(180%);
  border-bottom: 1px solid var(--glass-border);
}
```

### Cards
```css
.item, .layer-card, .note-block {
  background: var(--glass);
  border: 1px solid var(--glass-border);
  backdrop-filter: blur(12px);
}
```

### Fontes
- **Inter** (texto corrido)
- **Space Grotesk** (títulos h1/h2/h3)
- **IBM Plex Mono** (eyebrows, labels, monospace)

## Lições

- **Sempre oferecer opções visuais** quando o user reclama de design — é mais rápido construir 5 e deixar escolher do que iterar 5x num único
- **Frosted glass** é tendência forte em UI 2025-2026, combina com estética de "premium" que o user quer
- **CSS variables** facilitam trocar tema inteiro em 1 lugar
