## Contexto

Marcelo tentou adicionar manualmente um item a Produtos > Workshop, mas o item não aparecia depois de salvar. Toast mostrava "Salvo" mas a lista continuava com 3 items (sem o novo).

## Diagnóstico

Mavis rodou puppeteer pra reproduzir e descobriu **4 bugs acumulados**:

### Bug 1: `saveAddEdit` salvava em chave aninhada errada
- O user estava em `produtos/workshop` com `parentId='workshop'`
- O código fazia `STATE['produtos']['workshop'] = {...}` (aninhado)
- Mas o `collectAllItems` lê `STATE['produtos.workshop']` (flat com ponto)
- **Resultado**: item salvo em local errado, ignorado na renderização

### Bug 2: `bindItemActions` não passava `parentId`
- O click handler era `openAddEdit('add', currentView)` (sem 3o/4o args)
- `editContext.parentId` ficava `undefined`
- Mesmo com saveAddEdit correto, sem parentId salvava em `STATE[scopeKey]` em vez de `STATE[scopeKey + '.' + parentId]`

### Bug 3: `collectAllItems` só varria items da ESTRUTURA
- Pra produtos/operacao com sub, ele fazia `prod.items.forEach(...)` (só ESTRUTURA)
- Items custom do STATE eram ignorados
- **Resultado**: mesmo com STATE correto, item nunca era renderizado

### Bug 4: STATE legacy com chaves aninhadas
- Do bug 1, localStorage tinha `STATE['produtos']` (aninhado, lixo)
- Não causava erro direto mas poluía o saveState

## Correção

### Fix 1: `saveAddEdit` com flat key
```js
// ANTES
} else {
  if (parentId) {
    const parent = STATE[scopeKey]?.[parentId];
    if (parent && parent.items) parent.items[id] = item;
    else {
      STATE[scopeKey] = STATE[scopeKey] || {};
      STATE[scopeKey][parentId] = { id: parentId, nome: parentId, type: 'section', items: { [id]: item } };
    }
  } else {
    STATE[scopeKey] = STATE[scopeKey] || {};
    STATE[scopeKey][id] = item;
  }
}

// DEPOIS
const stateKey = parentId ? scopeKey + '.' + parentId : scopeKey;
if (mode === 'edit' && itemId) {
  item.id = itemId;
  STATE[stateKey] = STATE[stateKey] || {};
  STATE[stateKey][itemId] = item;
} else {
  STATE[stateKey] = STATE[stateKey] || {};
  STATE[stateKey][id] = item;
}
```

### Fix 2: `bindItemActions` passa `currentSubScope`
```js
// ANTES
const addBtn = document.getElementById('add-item'); if (addBtn) addBtn.addEventListener('click', () => openAddEdit('add', currentView));

// DEPOIS
const addBtn = document.getElementById('add-item'); if (addBtn) addBtn.addEventListener('click', () => openAddEdit('add', currentView, null, currentSubScope));
```

### Fix 3: `collectAllItems` inclui items custom
```js
// ANTES
prod.items.forEach(it => {
  const s = (STATE[fullKey] || {})[it.id];
  if (s) out.push({ ...s, ... });
  else if (!skipEmpty) out.push({ ... type: 'empty' ... });

// DEPOIS

    const s = stateItems[it.id];

  });
}
// items custom que estao no STATE mas nao na ESTRUTURA
Object.values(stateItems).forEach(s => { if (s && s.id && !seen.has(s.id)) out.push({ ...s, scopeKey, parentId: s.id, _prodKey: currentSubScope }); });
```

### Fix 4: `loadState` cleanup legacy
```js
function loadState() {
  try {
    const raw = localStorage.getItem(STATE_KEY);
    if (raw) {
      STATE = JSON.parse(raw);
      // cleanup legacy chaves aninhadas (bug antigo: salvava STATE['produtos'] em vez de STATE['produtos.workshop'])
      for (const k of ['produtos', 'operacao']) {
        if (STATE[k] && typeof STATE[k] === 'object' && !STATE[k].id) delete STATE[k];
      }
      // merge: items do INITIAL_DATA que faltam no STATE local sao adicionados (preserva edicoes)
      for (const scopeKey of Object.keys(INITIAL_DATA)) {
        if (!STATE[scopeKey] || typeof STATE[scopeKey] !== 'object') STATE[scopeKey] = {};
        for (const itemId of Object.keys(INITIAL_DATA[scopeKey])) {
          if (!STATE[scopeKey][itemId]) {
            STATE[scopeKey][itemId] = JSON.parse(JSON.stringify(INITIAL_DATA[scopeKey][itemId]));
          }
        }
      }
      saveState();
      return;
    }
  } catch(e) {}
  STATE = JSON.parse(JSON.stringify(INITIAL_DATA));
  saveState();
}
```

Aplicado em **todos os escopos** (gestao, operacao, produtos, sops, biblioteca, conhecimento) — não só produtos.

## Lições

- **Convenção de chave do STATE**: SEMPRE flat com ponto (`scope.sub`), NUNCA aninhado
- **Convenção `parentId` em `bindItemActions`**: SEMPRE passar `currentSubScope` como 4o arg
- **`collectAllItems`**: deve mesclar ESTRUTURA + STATE custom, não só varrer ESTRUTURA
- **`loadState` cleanup**: sempre limpar lixo legacy no boot
